- (쪽 1) ## 왜 했나
- (쪽 1) A사가 1차 미팅(10/8)에서 "수세하면 잔류 리튬은 줄어드는데, 1차 입자 표면이 바뀌는 게 장기 수명에 좋은지 나쁜지" 데이터를 보고 싶다고 했다. / 그래서 수세 조건(물:분말 비율 1:1, 1:2)에 따라 입도 분포와 500사이클 수명을 비교했다.
- (쪽 1) ## 한 것
- (쪽 1) - 공정: 물과 섞기 → 30분 교반 → 거르기 → 120 ℃ 건조 → 열처리 / - 입도: 레이저 회절, 시료당 3번 재서 평균 / - 수명: 코인셀, 0.5C, 500사이클 / - SEM: 2차 입자 ×6,350, 1차 입자 표면 ×31,750
- (쪽 1) ## 본 것
- (쪽 1) - SEM: 수세 뒤 1차 입자의 모서리가 둥글어졌다. 2차 입자(공 모양) 자체는 깨지지 않았다. / - 입도: D50은 10.2 → 10.1 → 10.0 µm로 거의 그대로. D90이 15.8 → 14.6 → 14.1 µm로 줄었다. /   분포 폭(span = (D90−D10)/D50)은 0.95 → 0.81(1:1) → 0.75(1:2). 1:2에서 21% 좁아짐. / - 수명: 500사이클 용량 유지율 수세 전 77%, 수세 후(1:2) 92%. 300사이클부터 차이가 벌어진다. / - 잔류 리튬은 1차 때 보고한 대로 줄었다(이번에 다시 재지는 않음).
- (쪽 1) ## 결론 (내 생각)
- (쪽 1) 수세하면 큰 입자 쪽(D90)이 줄고 표면이 매끈해져서, 장기 수명이 좋아진다. 1:2가 1:1보다 낫다. / A사가 걱정한 "표면이 바뀌면 수명에 나쁠까"는 적어도 500사이클까지는 반대로 좋아졌다.
- (쪽 1) ## 아직 모르는 것 / 조심할 점
- (쪽 1) - 수명은 코인셀이라 A사 풀셀에서 같을지는 모른다 → A사 500사이클 셀 데이터(10/24 약속)와 맞춰 봐야 함. / - 수명이 좋아진 원인이 잔류 리튬 감소인지, 입자 표면 변화인지 아직 나누지 못했다. / - 1:2는 물을 두 배 쓰니 공정 비용이 오른다. 양산에서 괜찮은지 A사 의견 필요.
